# 🌿 دودو ستور — متجر + لوحة تحكم

## تشغيله على جهازك (للتجربة)
1. نزّل **Node.js** (نسخة LTS) من nodejs.org
2. افتح الترمنال جوه الفولدر واكتب: `npm install`
3. انسخ `.env.example` باسم `.env`: `copy .env.example .env`
4. افتح `.env` (`notepad .env`) وغيّر `ADMIN_KEY` لكلمة سر من عندك
5. شغّل: `npm start`
6. المتجر: http://localhost:3000 — لوحة التحكم: http://localhost:3000/admin.html

> لو ويندوز منع npm: `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

## دليل صاحبة المحل (لوحة التحكم)
- **الطلبات:** كل طلب جديد بيظهر بعلامة حمرا. دوسي 📞 للاتصال أو 💬 للواتساب، وغيّري الحالة (جديد ← تم التأكيد ← في الطريق ← تم التسليم).
- **المنتجات:** دوسي ➕ إضافة منتج ← 📷 اختاري صورة (من الكاميرا أو المعرض) ← اكتبي الاسم والسعر ← حفظ. تقدري تعدّلي السعر أو تخفي المنتج لو خلص.
- **الأقسام:** أضيفي أو غيّري أقسام زي (أجبان، سجق، ألبان…).
- **الإعدادات:** رقم التليفون والواتساب، سعر الشحن، الشحن المجاني من كام، أقل طلب، وشريط إعلان، وزرار لقفل استقبال الطلبات مؤقتاً.
- **الدفع والتوصيل:** العميل يختار الدفع عند الاستلام أو فودافون كاش أو إنستا باي أو فيزا، ويحدد الفيوم أو القاهرة ويكتب العنوان. التوصيل محصور في المحافظتين. الدفع الإلكتروني يحتاج تأكيد يدوي؛ دفع الفيزا الحقيقي لا يعمل إلا بعد ربط بوابة دفع آمنة.
- ⚠️ **المنتجات التجريبية** (مكتوب جنبها "منتج تجريبي") لازم تتحذف قبل ما الموقع يتفتح للناس.

## الملفات
| الملف | وظيفته |
|---|---|
| `server.js` | نقطة البداية، بيشغّل كل حاجة |
| `src/config.js` | قراءة الإعدادات من `.env` |
| `src/db.js` | حفظ وقراءة البيانات (`data/db.json`) |
| `src/seed.js` | الأقسام والمنتجات التجريبية الأولية |
| `src/validate.js` | التحقق من كل بيانات جاية من العملاء ولوحة التحكم |
| `src/upload.js` | رفع الصور بأمان |
| `src/middleware.js` | حماية كلمة السر، منع السبام، هيدرز أمان |
| `src/routes/public.js` | عرض المتجر للعملاء |
| `src/routes/orders.js` | استقبال الطلبات وحساب الإجمالي |
| `src/routes/admin.js` | كل عمليات لوحة التحكم |
| `public/index.html` `style.css` `app.js` | صفحة العملاء |
| `public/admin.html` `admin.js` | لوحة التحكم |
| `public/logo.jpg` | اللوجو |
| `data/` | بيتعمل فيه `db.json` وفولدر `uploads` (الصور) — **خدي منه نسخة احتياطية** |

## ملاحظات النشر
- الموقع محتاج استضافة بتشغّل Node.js وبتحفظ الملفات بشكل دائم (Persistent Disk)، وإلا الطلبات والصور هتضيع.
- على الاستضافة اظبطي المتغيرات `ADMIN_KEY` و `DATA_DIR` (مسار القرص الدائم) من إعدادات الموقع بدل ملف `.env`.
